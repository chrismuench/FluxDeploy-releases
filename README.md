# FluxDeploy downloads

Installers and relay packages for FluxDeploy. Get the latest from the Releases page:
https://github.com/chrismuench/FluxDeploy-releases/releases/latest

- InstallFluxDeploy-<version>-x64.exe - Windows installer (Core and Windows relay)
- FluxDeploy-Relay-<version>-linux-x64.tar.gz - Linux relay
